# Logo Atelier Facette (v1)

> Nom provisoire. Symbole : taille hexagonale (choisi le 2026-10-09 face à la taille émeraude, plus lisible en petit).

## Fichiers

| Fichier | Usage |
|---|---|
| `photo-profil-1080.png` | Photo de profil Instagram, TikTok, Google |
| `symbole-512.png` | Icône du site (favicon), WhatsApp |
| `logo-horizontal.png` | En-tête de site, devis, factures, signature d'email |
| `logo-horizontal-sombre.png` | Fonds sombres (pied de page du site, publications) |
| `logo-empile.png` | Cartes de visite, publications carrées, flyers |
| `symbole.svg`, `symbole-clair.svg` | Symbole seul en vectoriel, pour fond clair / fond sombre |
| `logo-horizontal.svg`, `logo-horizontal-clair.svg` | Logo horizontal en vectoriel, pour fond clair / fond sombre |
| `logo-empile.svg`, `logo-empile-clair.svg` | Logo empilé en vectoriel, pour fond clair / fond sombre |

Les SVG ont un fond transparent et s'agrandissent sans perte (véhicule, panneau de chantier).

## Typographie

Fraunces (Google Fonts, licence libre OFL, usage commercial autorisé), graisse 460, taille optique 48.

## Pour un imprimeur

La police est intégrée dans les SVG, mais le texte n'est pas encore converti en tracés. Demander à l'imprimeur de "vectoriser le texte" ou le faire dans Inkscape (gratuit) : sélectionner le texte, menu Chemin > Objet en chemin.

# langues/

Livrables pour l'apprentissage de l'anglais, de l'espagnol et du portugais : plans d'apprentissage, fiches de vocabulaire (métier bâtiment, IA, business), fiches de grammaire, exercices et corrigés, dialogues de mise en situation, suivi de progression.

Un sous-dossier par langue (`anglais/`, `espagnol/`, `portugais/`), puis un dossier par projet nommé `AAAA-MM-JJ_sujet/` (ex. `anglais/2026-10-15_vocabulaire-entretien-embauche/`). Voir [../README.md](../README.md) pour la convention complète.

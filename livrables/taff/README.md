# taff/

Livrables pour la recherche d'emploi : CV ciblés, lettres de motivation, préparation d'entretiens, suivi des candidatures, listes d'entreprises à démarcher.

Un dossier par candidature ou chantier de recherche, nommé `AAAA-MM-JJ_entreprise-poste/` ou `AAAA-MM-JJ_sujet/`. Voir [../README.md](../README.md) pour la convention complète.

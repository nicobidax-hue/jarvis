# Contenu : l'offre résine d'Atelier Facette

> Notes techniques données par Nicolas (2026-10-13), pour développer la page `site/beton-cire-resine.html`, le choix du formulaire, le trieur de devis et le futur fichier de prix. Rien n'est inventé : ce qui manque est listé dans « À préciser ».

## Ce qui vaut pour toutes les résines

- **Où :** partout (pièces de vie, garages, locaux professionnels...)
- **Supports :**
  - chape béton : le meilleur support
  - carrelage existant : possible s'il ne se décolle pas
  - ancienne résine : possible
- **Épaisseur :** de 2 à 5 mm
- **Avantages :** pas de joints, facile d'entretien, dure dans le temps

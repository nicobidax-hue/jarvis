# applications/

Outils, scripts et automatisations : chatbots, workflows d'automatisation, scripts Python, petits outils internes, démos pour les clients IA.

Un dossier par outil, nommé `AAAA-MM-JJ_nom-de-l-outil/`, avec un `README.md` qui explique comment l'installer et l'utiliser. Les clés d'API se lisent depuis le `.env` à la racine, jamais en dur dans le code. Voir [../README.md](../README.md) pour la convention complète.

# ia/

Tout ce qui vient du parcours de formation IA et du freelance IA : prompts, workflows n8n, installation des outils (n8n), démos pour les clients. C'est aussi le futur portfolio pour le freelance.

Un dossier par projet, nommé `AAAA-MM-JJ_nom-du-projet/`, avec un `README.md` ou un `GUIDE.md` qui explique le contexte et l'utilisation. Les clés d'API se lisent depuis le `.env` à la racine, jamais en dur dans le code. Voir [../README.md](../README.md) pour la convention complète.

Les outils et scripts sans IA (remplissage de CV, envoi de mails, etc.) vont dans `../applications/`.

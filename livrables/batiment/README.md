# batiment/

Livrables pour la branche rénovation intérieure (spécialité sols résine et béton ciré) : devis, factures types, fiches techniques, plaquettes commerciales, comparatifs de statut juridique, prospection.

Un dossier par projet ou chantier, nommé `AAAA-MM-JJ_nom-du-projet/` (ex. `2026-11-02_devis-beton-cire-cuisine/`). Voir [../README.md](../README.md) pour la convention complète.
